# One test seam: the daemon boundary with injected fakes

All behaviour tests drive hos through its public surfaces: the client API and event stream (used by the web app) and the bus (used by agents). The daemon is started in-process with injected fakes from `src/fakes/`: agent runtime (scripted events, context growth, bus calls, permission requests, file writes, token spend, provider windows), transport identity, clock, notifier, secrets, a passkey authenticator and machine (memory pressure, thermal and battery readings, boot time, the idle-sleep assertion and setup facts for the doctor). git and tmux run for real in temp dirs and on a separate tmux socket. Tests assert observable outcomes, never internal tables or private functions. The seam is agreed, so a test-first workflow needs no further confirmation. Real adapters (the Claude driver, harnesses, transports) get small opt-in live contract tests (`*.live.test.ts`) that check they emit the same normalized events the fakes script.
